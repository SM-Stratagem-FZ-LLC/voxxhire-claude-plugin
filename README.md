# Voxxhire for Claude

Claude Code plugin: one hosted MCP server (OAuth via Voxxhire account, same wallet/history as the website) + three skills.

Install: `/plugin marketplace add SM-Stratagem-FZ-LLC/voxxhire-claude-plugin` then `/plugin install voxxhire@voxxhire` or `claude --plugin-dir .`.
Claude.ai / Desktop: Settings → Connectors → Add custom connector → `https://voxxhire-chatgpt-production.up.railway.app/mcp`.

MCP endpoint is shared with the ChatGPT gateway (`integrations/chatgpt`). Switch `.mcp.json` when a branded domain exists.
Public listing: Anthropic Connectors Directory submission (form) — see docs/integrations/claude-submission.md.
